# 0.8.2 更新说明

整理日期：2026-09-09。汇总“规划全新版本体验升级”和“整体优化”两个线程的已实施改动，基于 0.8.1。

## 模型与图像参数

- 画廊和画布新增 `gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`，归入现有 Images API 生图配置，分别使用生成和编辑端点。
- 两个新模型支持 `auto`（默认）、`low`、`medium`、`high`、`xhigh`、`max` 六档质量。模型和扩展质量可持久保存；切回 GPT Image 2 时，后两档降为 `high`。
- 复用现有 4K 尺寸预设与校验：边长不超过 3840，均为 16 的倍数，长短边比不超过 3:1，总像素为 655,360—8,294,400。
- 原生透明输出使用 `background=transparent` 配合 PNG 或 WebP；保留 `auto/opaque` 背景选项，JPEG 自动使用不透明背景。
- 画布参数快照和 API 返回的实际参数保留新增质量值。两个 GPT Image 2.5 模型互切时保留尺寸、质量和数量。

2026-09-09 核对 OpenAI 官方图像生成指南与两个模型页。官方将高于 `2560x1440` 的分辨率标为实验性；GPT Image 2 的官方尺寸约束也支持上述 4K 范围。固定服务的模型可用性仍由服务端决定。

官方资料：

- `https://developers.openai.com/api/docs/guides/image-generation`
- `https://developers.openai.com/api/docs/models/gpt-image-2.5-flare`
- `https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst`

## 界面细节

- 导航项使用固定文字与滑动选中背景，统一顶部操作按钮尺寸和对齐。
- 优化浅深色切换的小幅动画，并尊重系统减少动态效果的偏好。
- 统一参数控件、搜索栏、按钮的高度、间距、圆角和聚焦状态，调整输入栏底部操作对齐。
- 长标题和窄屏布局保持现有页面结构。此前撤回的大改版原型不属于本次发布。

## 整体优化

- 修复离开画布后生成结果无法写回、旧请求覆盖新结果及删除项目后晚到结果回写的问题。
- 将取消信号传递到图片请求、轮询、下载、Blob 参考图和遮罩转换。
- 修复 Service Worker 清理误删业务图片缓存；本次界面缓存版本更新为 0.8.2。
- IndexedDB 等待事务提交才确认保存；复用连接并处理关闭、回滚与重连。
- 主存储失败时优先恢复备用新值；同键写入串行化，删除失败保留标记。
- Canvas Agent 及附件纳入画布库完整备份；导入预检、独立资源键与引用重映射避免覆盖已有内容。
- 资源引用收集覆盖历史参考图与透明处理原图；透明增强失败保留原始结果。
- WebDAV 合并时保留同步期间的本地编辑；Canvas Agent 读取最新画布状态。
- 画廊每页挂载 90 个任务；画布、Agent 和弹窗按需加载；减少无变化的持久化写入并合并连续保存。
- 更新 axios、nanoid、react-router-dom 及兼容范围内的传递依赖；加入 PR 构建与测试工作流。
- 发布前复查补升 Vitest 至 4.1.11，并将 Miniflare 的 Sharp 依赖限定为已修复的 0.35.4 及其兼容补丁，处理新增的开发工具依赖告警。
- 发布检查修正初始化任务筛选时的原始索引对应关系。

完整修复说明见 [整体优化日志](changelog-2026-09-09.md)；该文中的性能数据和验证数字属于此前快照。
