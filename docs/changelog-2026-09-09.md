# 更新日志：数据可靠性、画布生成与性能改进

本文保留“整体优化”线程原始验证快照；与界面细节、新模型接入合并后的版本说明见 [0.8.2 更新说明](release-0.8.2.md)。

**发布状态：未发布，基于 0.8.1。** 本日志整理于 2026-09-09，覆盖本线程的仓库研究、Bug 修复、功能补齐、性能改进和验证工作。代码验证完成于 2026-09-08；本线程未修改应用版本号，尚未提交或部署。

本次完成研究报告中 F01—F10 共 10 项已复现问题的修复，补齐 Canvas Agent 备份与导入保护，改善大型图库、按需加载和高频保存，并新增持续集成检查。

**新增功能**

- 新增画布库“全部导出（含 Agent）”：一次备份全部画布、项目引用的图片与媒体、独立 Canvas Agent 对话和附件。单项目／选中项目导出仍只包含对应项目。
- 新增画布保存状态：显示“保存中”“已保存”“保存失败，点击重试”。写入失败保留待保存内容，页面隐藏时提前尝试保存。
- 新增画布导入预检：检查备份版本、项目与节点 ID、节点尺寸、视口、连线、对话结构，以及资源是否存在、大小是否一致、引用是否完整。
- 新增画廊分页：每页 90 个任务，筛选条件变化时返回第一页，任务数量减少时修正页码；选择状态跨页保留，框选作用于当前页。
- 新增 GitHub Actions 构建与测试工作流：PR 和 main／master 推送时，在 Node 22 环境依次执行 `npm ci`、`npm run build`、`npm test`。

| F02 | 离开画布后，已完成生成的结果没有写回项目 | 节点与连线直接归项目状态管理；返回列表或切到画廊后，结果仍保存到原项目。 |
| F03 | 资源清理漏算生成历史参考图 | 清理、导出和 WebDAV 共用完整引用收集，保留历史参考图及透明处理原图；导出缺失资源时明确报错。 |
| F04 | IndexedDB 请求成功但事务未提交，就报告保存成功 | 等待事务提交完成才返回成功；事务回滚或中止返回失败。 |
| F05 | “停止生成”没有取消底层图片请求 | 取消信号贯通图片 API、SDK、轮询、响应体读取、图片下载和桥接转换，并正确释放监听器。 |
| F06 | Gemini 部分重试路径无法处理 Blob URL 参考图 | 桥接层统一将参考图和遮罩转换为 Data URL，支持从持久化资源键恢复。 |
| F07 | 画布“透明输出增强”设置未实际生效 | 接入辅助提示词与背景去除流程，同时保存原图；后处理失败时提示并保留原始结果。 |
| F08 | 历史节点重试参数随全局设置变化 | 先读取历史参数快照，再叠加本次明确修改；新节点继续继承全局默认值。 |
| F09 | 启动加载的旧任务列表覆盖期间新增的任务 | 初始化去重、提交等待初始化，并合并加载期间的任务变化，避免旧草稿覆盖当前输入。 |
| F10 | 主库写入失败后，恢复时读不到备用存储的新数据 | 同键写入串行执行，读取等待待写任务，优先恢复备用新值；主库恢复后清理备用数据，删除失败时用标记阻止旧值重新出现。 |

**画布、Agent 与并发稳定性**

- 按项目保留生成请求状态；重新进入项目时能识别仍在进行的任务。
- 已取消或被重试取代的请求不再覆盖新结果；删除项目时取消对应请求，晚到的结果不会重建已删除项目。
- 批量生成时，删除后又撤销恢复的目标节点不接收旧请求结果；生成写回保留期间的位置编辑。
- 编辑器按项目 ID 隔离局部状态，避免切换项目时沿用上一项目的界面状态；异步资源恢复不覆盖已经编辑过的节点。
- 将生成上下文恢复纳入完整的异常处理与请求清理流程，避免恢复失败后一直显示生成中。
- 修复 Canvas Agent 清空选择操作：`canvas_select_nodes({ ids: [] })` 现在可以正常执行，同时拒绝格式错误的节点 ID。
- Canvas Agent 每轮读取和执行工具时获取最新画布状态，能看到期间发生的生成结果和用户编辑。
- WebDAV 应用合并结果时保留同步期间的本地新增、编辑和删除；资产恢复后再次核对最新状态。
- WebDAV 日志更新不再先清空整个存储，避免删除同步期间新增的日志。

**备份与存储可靠性**

- 导入为项目和资源分配独立 ID／存储键，重映射历史参考图等引用，避免覆盖已有内容。
- 导入在内容载入前失败时，只清理本次创建的资源；内容已经载入但最终保存失败时，保留内存内容并提示重试或重新导出。
- 导入的 Agent 附件使用备份内的图片数据恢复显示地址，不再依赖原浏览器的临时 Blob URL。
- 保留导入期间新增或编辑的对话；旧的会话加载响应不再覆盖已经恢复的内容。
- 备份版本继续使用 3，新增可选的 `agentConversations` 字段，兼容原有版本 3 画布备份。
- 复用 IndexedDB 连接，处理打开失败、连接关闭和版本变化，减少重复打开并允许重新连接。
- 图片仅保存到内存时明确报告持久化失败，避免导入或同步误报资源已可靠保存。
- 覆盖同一资源键或删除媒体时回收旧 Object URL；取消期间产生的新图片会按生成保存流程清理。

**性能优化**

- 画布工作区、全局 Agent、设置、任务详情和遮罩编辑器按需加载；画布列表与完整项目编辑器分别加载，弹窗只在显示时挂载。
- 宿主持久化增加字段选择结果缓存与内容去重，减少无变化的序列化和 localStorage 写入。
- Canvas Agent 合并尚未提交的中间草稿，避免逐次排队保存全部历史对话；保留最终内容及失败后的重试能力。
- 画布保存使用串行队列，连续更新时继续保存最新内容，失败时保留待写状态。

**兼容性与后续事项**

- 当前仍以完整项目数组保存画布，尚未改为按项目增量持久化；页面隐藏时尝试保存不保证强制关闭前完成所有异步写入。
- 已改善 Object URL 回收，但尚未实现有容量上限的跨项目缓存。
- ZIP 压缩／解压仍同步执行，尚未迁移至 Worker；导入校验尚未穷尽扩展元数据、恶意压缩体积和跨项目资源冲突。
- 宿主全局 Agent 仍存在整体集合写入；本轮合并保存优化针对 Canvas Agent。
- WebDAV 尚无双向删除标记协议，也未接入 Canvas Agent 对话；远端旧项目仍可能在后续合并中重新出现。
- 构建仍有部分代码块超过 500 kB，以及画布 store 混用静态／动态导入的提示。
- 未验证真实 WebDAV、多端冲突、Safari／移动浏览器、Docker／Cloudflare 部署或远端 GitHub Actions 执行。取消信号到达前端请求不代表供应商已经停止计算或计费。
