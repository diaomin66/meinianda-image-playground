## 备份、保存与 Agent

- 画布库新增“全部导出（含 Agent）”，包含全部项目、引用媒体及独立 Canvas Agent 对话和附件。单项目或选中项目导出继续只包含对应项目。备份版本仍为 3，新增的 `agentConversations` 是可选字段，兼容原有版本 3 备份。
- 新增 `canvas-import.ts`。导入前检查版本、项目／节点 ID、视口与尺寸、连线、对话及资源引用，资源不存在或大小不符时拒绝。为导入项目和资源分配新 ID／键，避免覆盖已有内容；载入前失败只清理本轮新建资源。
- 导入的 Agent 附件地址从 `dataUrl` 恢复，不依赖原浏览器的 Blob URL。读取期间新完成的会话加载、保存期间发生的对话编辑均保留；旧的初始化响应不会覆盖已导入的对话。
- 内容已经载入后，如果最终保存失败，保留内存中的项目、对话和资源，并明确提示保留页面、重试或重新导出。此时不能把导入成功显示为已持久保存；画布保存按钮只重试画布保存，Agent 内容可重新导出保护。
- 画布顶部增加“保存中／已保存／保存失败，点击重试”；保存任务串行执行，失败时保留待保存内容，页面隐藏时提前尝试刷新待保存队列。
- Canvas Agent 的连续对话保存合并中间草稿。故障注入中，一次存储未完成时追加 100 次草稿更新，最终仅写入 2 次并保留最新草稿。
- `canvas_select_nodes({ ids: [] })` 可以清空选择。直接 Agent 每轮读取与执行工具时取最新画布快照，避免继续使用本轮开始时的旧节点状态。
- WebDAV 应用远端合并结果前保留本轮同步期间发生的本地编辑、删除和新增；资产资源恢复后再次核对状态。日志写入不再先清空整个存储，避免误删期间新增的日志。

备份入口和数据范围已同步更新到 `README.md`、宿主设置及画布设置。WebDAV 明确采用合并备份语义，不承诺传播删除操作，也不包含独立 Canvas Agent 对话。

## 后续优化与未验证范围

下面是仍未实施的设计改进，不计作本轮已完成项：

1. **按项目增量持久化**：画布仍以 400 ms 延迟保存完整项目数组，视口仍有既有延迟；需单独设计数据库迁移。页面隐藏时刷新队列不能保证强制关闭浏览器前所有异步操作完成。
2. **Object URL 容量预算**：已修复同键覆盖和删除时的旧 URL 回收，尚未实现跨项目的有界缓存及视图引用计数。
3. **大备份处理**：ZIP 仍使用同步压缩／解压，尚未迁移到 Worker。导入校验覆盖主要结构和引用，尚未对全部可扩展 metadata 字段、恶意压缩体积及跨项目冲突资源声明建立完整限制；宿主导入格式也未作全量重新设计。
4. **全局 Agent 增量写入**：本轮优化了 Canvas Agent 的排队写入；宿主全局 Agent 仍有整体集合持久化，宜后续按会话／消息改造。
5. **真正的双向 WebDAV 删除同步**：尚无删除标记协议，远端旧项目可能被重新合并回来；Canvas Agent 尚未加入 WebDAV 范围。
6. **进一步减少大代码块**：构建仍提示部分 chunk 超过 500 kB，以及画布 store 同时被静态、动态导入；本轮没有提高警告阈值来隐藏它们。

没有验证真实 WebDAV 服务器、多端同步冲突、Safari／移动浏览器、Docker／Cloudflare 部署，也没有向真实模型供应商发请求。取消测试证明前端请求和下载收到信号，不证明供应商已停止计算或计费。
