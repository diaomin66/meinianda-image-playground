# 0.9.0-beta.1 更新说明

整理日期：2026-09-13。基于 0.8.2 的 beta 测试版，新增人物聊天工作区并完善生图链路。

## 人物（beta）

- 自建名字、人格、外貌与开场白；头像独立上传，缺省头像使用名字中的最多两个字，多张固定参考图仅用于生图。
- 人格原文作为聊天唯一系统提示词，支持 OpenAI Responses 与 Gemini 原生 SSE 文字流和函数调用。
- 主 Agent 编写画面提示词，经独立副脑优化后直接传给生图模型。普通聊天和副脑不附带固定参考图像素；用户主动发来的附件及已生成图片仍可用于聊天上下文。
- 一次请求多张图片时，逐张并发优化不同提示词并并发生图；重复方案会重写，重复图片会有限重试，部分失败不丢弃其他成功图片。
- 图片在后台生成并送回原对话，人物可继续自然交流；技术进度、请求参数和错误放入单独日志。
- 独立历史对话、相册、单条及批量删除；执行删除时跳过仍在回复或生图的对话，并清理对应日志。
- 对话日志支持筛选与导出，隐藏密钥、认证信息、图片字节和模型签名。
- 生活日程根据人格、日期、近期对话与历史日程生成穿搭和安排，作为聊天上下文参与当轮回复；支持每日切换时间与手动重写。日程失败时继续正常聊天，停止回复会向日程请求传递取消信号。

## 链路与界面

- Gemini 语言使用原生 `streamGenerateContent?alt=sse`，图片使用非流式 `generateContent`；完善图片数据识别、流结束判断、文字分片显示和工具回执。
- 人物生图复用画廊的配置与参数映射，竖图、方图和横图通过 Gemini `generationConfig.imageConfig` 传入。
- 本地开发服务器为固定服务提供同源转发并支持长生图响应；连接中断明确反馈，不盲目重发生成请求。
- 统一蓝色强调色、圆角菜单和抽屉、键盘选择、进入与退出动画；尊重减少动态效果偏好，图片查看器跟随浅深主题。
- 人物数据和相关图片纳入本地持久化与全局备份，兼容既有浏览器数据。

## beta 范围与发布方式

- 应用、锁文件和 PWA 缓存版本统一为 `0.9.0-beta.1`，主导航与人物设置标注 beta。
- 日程当前在聊天时按日期生成或手动重写；时间设置是日期切换边界。尚不提供关闭页面后的定时运行、主动消息推送、节假日库或自定义日程模板。
- 后台图片任务依赖当前页面保持运行，关闭或刷新页面会中断请求。升级前可通过全局设置导出人物及聊天数据；画布使用其独立备份入口。
- 本地同源转发属于 Vite 开发服务；静态部署需要服务商允许跨域或部署环境自行配置代理。
- Docker 发布流程为 beta 生成完整版本标签与 `beta` 标签，预发布版本不更新稳定 `latest` 和次版本标签。
- 本次通过 PR 交付。合并后如创建 GitHub Release，应选择预发布并使用 `v0.9.0-beta.1` 标签；创建标签会触发现有部署工作流。

## 验证

- `npm run build` 通过；60 个测试文件、678 项 Vitest 测试通过；`git diff --check` 通过。
- 隔离浏览器检查 320、375、390、640、768、1024、1280、1440px 八档导航布局，确认「人物（beta）」完整位于圆角选中框内。
- 浏览器验证人物设置、批量删除、忙碌对话保护、删除后的新对话兜底和刷新恢复，以及浅深色图片查看器。
- 模拟接口验证 9 次副脑优化、10 次图片请求（含一次重复图片重试）得到 9 张独立图片，覆盖多图并发、固定参考图隔离、竖图参数和后台继续聊天。
- 构建仍有既有大代码块和画布 store 混合导入提示。真实供应商付费请求不属于这轮发布整理的验证范围，远端 CI 结果以 PR 检查为准。
